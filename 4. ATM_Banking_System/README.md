# 🏦 ATM Banking System (Python)

A simple command-line ATM application built using Python.

## Features

- PIN Authentication
- Check Balance
- Deposit Money
- Withdraw Money
- Transaction History
- Change PIN
- Menu Driven
- Input Validation

---

## Python Concepts Used

- Variables
- Input / Output
- Functions
- if-elif-else
- while loop
- for loop
- range()
- Lists
- Global Variables
