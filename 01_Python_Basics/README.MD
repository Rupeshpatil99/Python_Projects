# 🐍 Python Mini Projects

Three small beginner-friendly projects, each built to practice one topic from my notes:

| # | Project | Topic Practiced |
|---|---------|------------------|
| 1 | [Contact Book](./01-data-structures-contact-book) | Lists, Dictionaries, Tuples, Sets |
| 2 | [Random Password Generator](./02-python-basics-password-generator) | Python basics — variables, functions, `import`, using a library |
| 3 | [Student Grade Calculator](./03-conditionals-grade-calculator) | `if` / `elif` / `else`, comparison & logical operators |

## How to run any project
```bash
cd project-folder-name
python3 main.py
```

No external installs needed — everything uses Python's built-in standard library.

## Why these projects?
Each one is deliberately small (under ~100 lines) so it's easy to read in one sitting,
but each one touches every method/concept from the matching notes file at least once.
Good first commits for a GitHub portfolio!
